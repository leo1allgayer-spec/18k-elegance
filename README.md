# Elegance 18K

Front-end institucional e vitrine inicial do e-commerce Elegance 18K.

## Estrutura

- `index.html`: página principal.
- `styles.css`: identidade visual e responsividade.
- `script.js`: carrossel da hero.
- `assets/`: logo, fotografias e imagens temporárias de produtos.

## Publicação no Cloudflare Pages

Este projeto é um site estático e não precisa de comando de build.

- Framework preset: `None`
- Build command: deixar vazio
- Build output directory: `/`
- Production branch: `main`

Depois de conectar o repositório GitHub, cada atualização enviada para `main`
gera uma nova publicação.

## Observações

As fotografias dos produtos foram geradas por IA para apresentação inicial e
devem ser substituídas pelas imagens reais do catálogo antes do lançamento.
